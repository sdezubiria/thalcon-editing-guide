# Thalcon editing guide

How to change the Thalcon site in Framer: the stats, logos, jobs, globe states, videos and photos. One static page in the site's own design system, served with GitHub Pages.

- `index.html` and `guide.css`: the page
- `img/`: screenshots of each editable part of the site

To update the screenshots, run `framer-build/.cache/capture-guide.mjs` from the site repo with the site served on port 8080, pointing it at `img/`.
